## 3. 3D contribution calendar (one-time setup)

The "🧊 My Year in 3D" section shows `./profile-3d-contrib/profile-night-view.svg`, generated by the [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib) Action.

1. Push the repo (the workflow `.github/workflows/profile-3d.yml` is already included).
2. Repo → **Settings → Actions → General → Workflow permissions** → select **Read and write permissions** → Save.
3. Repo → **Actions** tab → **GitHub-Profile-3D-Contrib** → **Run workflow** (it also runs daily and on push).
4. It creates the `profile-3d-contrib/` folder with the SVGs and commits them. After it finishes, the 3D calendar appears in your README.

> The image link shows as broken until that workflow has run once — that's expected.
> Want a different look? The action also outputs `profile-green-animate.svg`, `profile-season-animate.svg`, `profile-night-view.svg`, `profile-gitblock.svg`, and more. Just change the filename in the README's `<img src=...>`.
